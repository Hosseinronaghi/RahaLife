# Raha Life — v0.2.0

Raha Life is a multilingual, offline-first personal organizer for tasks, medicines, appointments, notes, shopping, habits, birthdays, calendars, and daily finance.

## What is working now

- Premium Material Design 3 interface for mobile and desktop
- Persian RTL and English LTR
- Persian primary date with compact Gregorian date, reversed in English
- Vazirmatn for Persian and Inter for English through `google_fonts`
- Light, dark, and system themes
- Selectable emerald, blue, purple, and orange accent colors
- Persistent language, theme, text size, accent, and dashboard visibility settings
- Conditional Today dashboard with a single empty state
- Quick add and module-specific add forms
- Local persistence for active entries
- Details, completion toggle, and deletion
- Global search and filters
- Month, week, and day calendar views
- Basic reports and progress summaries
- Birthday support
- AI API settings with secure key storage
- Explicit Coming Soon states instead of dead buttons

## GitHub Actions outputs

Open **Actions → Build Raha Life → Run workflow**. The workflow creates:

### Android

- `Raha-Life-universal-release.apk`
- `Raha-Life-arm64-v8a-release.apk`
- `Raha-Life-armeabi-v7a-release.apk`
- `Raha-Life-x86_64-release.apk`
- `Raha-Life-release.aab`

### Windows

- `Raha-Life-Windows-x64-portable.zip`

### Web

- `Raha-Life-Web-release.zip`

Each artifact package also includes a SHA-256 checksum file.

## Repository setup

Upload the contents of this folder to the root of the GitHub repository. `pubspec.yaml`, `lib`, `test`, `.github`, and `docs` must appear directly in the repository root.

Platform projects are generated by GitHub Actions. Local setup is optional:

```bash
flutter create --platforms=android,ios,windows,macos,linux,web --org com.raha --project-name raha_life .
flutter pub get
flutter gen-l10n
dart run build_runner build --delete-conflicting-outputs
flutter analyze --fatal-infos
flutter test
```

## Font note

The source does not include font binary files. The current implementation uses the official `google_fonts` package for Vazirmatn and Inter. For a fully offline production release, licensed font assets should later be bundled by the project owner.
