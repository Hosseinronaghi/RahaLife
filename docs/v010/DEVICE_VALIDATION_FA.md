# چک‌لیست بررسی رها لایف روی دستگاه

این چک‌لیست معیار تأیید پیش از انتشار عمومی است. نتیجهٔ هر مورد با مدل دستگاه، نسخهٔ سیستم، نسخهٔ برنامه و شناسهٔ ساخت ثبت شود. از حساب و دادهٔ ساختگی استفاده کنید.

| آزمون | مراحل | نتیجهٔ لازم |
|---|---|---|
| ارتقای اندروید | نسخهٔ قبلی با امضای انتشار را نصب کنید. یک یادداشت غنی، پیوست، یادآور و تنظیمات متمایز بسازید. همان شناسه و امضا، با شمارهٔ ساخت بالاتر، روی نسخهٔ قبلی نصب شود. | نصب بدون حذف برنامه؛ متن، فایل، تنظیمات و اعلان بعد از باز کردن نسخهٔ تازه برقرارند. |
| قطعی و تعارض سینک | روی دو دستگاه وارد حساب آزمایشی شوید. یادداشت مشترک را همگام کنید؛ هر دو آفلاین و هر کدام یادداشت را جدا ویرایش کنند. اتصال را برگردانید و از رابط تعارض یک نسخه را انتخاب کنید. | هر دو نسخه قبل از حل قابل مشاهده‌اند؛ پس از انتخاب، دستگاه‌ها یکسان می‌شوند و تغییرهای مستقل عقب نمی‌مانند. |
| تأیید مقصد | روی دادهٔ آزمایشی، حساب یا نشانی سرور را تغییر دهید. ابتدا تأیید نکنید، سپس مقصد جدید را دستی تأیید کنید. | مقصد جدید پیش از تأیید هیچ محتوایی نمی‌گیرد. |
| اعلان و راه‌اندازی مجدد | مجوز اعلان را بدهید؛ دو یادآور نزدیک بسازید، یک مورد را ویرایش کنید و برنامه را ببندید. برای دور بعد دستگاه را راه‌اندازی مجدد و زمان محلی را عوض کنید. | یادآور ویرایش‌شده مطابق وقت انتخابی و یادآور مستقل فقط یک بار ظاهر شوند. محدودیت‌های سیستم و اختلاف زمان ثبت شوند. |
| بکاپ و بازیابی | بکاپ رمزگذاری‌شده با پیوست بسازید و روی نصب تازه بازیابی کنید. یک بار فایل خراب و یک بار کلید نامعتبر بدهید. | داده و پیوست سالم منتقل شوند؛ بازیابی نامعتبر تغییر ناقص ایجاد نکند. |
| آیفون و مک | روی هدف واقعی با بستهٔ دارای امضای مناسب باز کنید. باز و بسته شدن برنامه، ذخیرهٔ یادداشت، شبکهٔ محلی و اعلان را بررسی کنید. | شروع و ذخیره قابل تکرار باشند. Archive بدون امضا و DMG با امضای محلی مدرک توزیع عمومی نیستند. |
| راست‌چین و دسترس‌پذیری | در عرض گوشی و دسکتاپ، حالت روشن/تیره، متن بزرگ و صفحه‌کلید را برای یادداشت، خانه و سینک امتحان کنید. | فیلدها هم‌پوشانی نداشته باشند و دکمه‌ها با صفحه‌خوان/صفحه‌کلید قابل دستیابی باشند. |

برای دریافت خروجی موقت: GitHub Actions → اجرای ساخت مربوط → Artifacts. برای ارتقای Android از بسته‌ای که با گواهی همان نسخهٔ نصب‌شده امضا شده استفاده کنید. بستهٔ پیش‌نمایش ممکن است تنها برای نصب آزمایشی جداگانه مناسب باشد.
