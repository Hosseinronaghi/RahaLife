# UI captures

Logical viewport: mobile 390×1000, desktop 1440×1000; pixel ratio 1.5. Both mobile themes and desktop light were visually inspected. These are not native-device or browser screenshots, and do not represent all app screens. Regenerate with `flutter test test/ui_capture_test.dart`.
