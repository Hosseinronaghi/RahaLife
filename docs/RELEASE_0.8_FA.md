# رها لایف ۰٫۸ — گزارش پیاده‌سازی و تحویل

تاریخ بررسی: ۱۵ سپتامبر ۲۰۲۶. نسخهٔ سورس: `0.8.0+15`؛ پایگاه داده: schema 7؛ سرور: protocol 3.

این بسته نسخهٔ قابل بررسی توسعه است. انتشار عمومی، نصب روی گوشی واقعی و تأیید محیط عملیاتی هنوز انجام نشده است. مبنا دو ZIP نسخهٔ ۰٫۷ ارسال‌شده بود؛ فایل‌های بستهٔ changed-files با نسخهٔ کامل یکسان بودند. متن کامل گفت‌وگوی اشتراک‌گذاری‌شده قابل دریافت نبود؛ بنابراین تطبیق صددرصد با تمام جزئیات آن گفت‌وگو تأیید نمی‌شود.

## تغییرات اصلی

### داده، مهاجرت و همگام‌سازی

- ثبت تغییر رکورد و صف ارسال در تراکنش؛ جلوگیری از حذف رکورد تازهٔ دستگاه دیگر هنگام ذخیرهٔ یک فهرست قدیمی.
- ادغام تغییر فیلدهای مستقل؛ نگهداری تعارض تغییر هم‌زمان همان فیلد به جای بازنویسی بی‌صدا.
- clock برداری برای تشخیص هم‌زمانی؛ شمارندهٔ نسخه به تنهایی معیار برتری دستگاه نیست.
- تأیید ارسال بر اساس changeId دقیق، اعمال صفحهٔ دریافت و cursor در تراکنش، ارسال دسته‌ای محدود، توقف در پاسخ نامعتبر یا تعارض.
- اجرای ترتیبی عملیات sync/backup/restore، یکی‌شدن درخواست‌های هم‌زمان sync، نمایش خطای ذخیره و وضعیت انتظار.
- مهاجرت insert-only، حفاظت از tombstone، اعتبارسنجی شناسه‌های تکراری، مهاجرت خرید و اقلام آن در یک تراکنش.
- حذف تاریخچهٔ ارسال‌شدهٔ قدیمی‌تر از ۹۰ روز؛ tombstoneها برای جلوگیری از بازگشت حذف‌ها حفظ می‌شوند.

### بکاپ و پیوست

- بکاپ از رکورد منطقی و ادغام محافظه‌کارانه؛ فایل SQLite بازِ برنامه بازنویسی نمی‌شود.
- تنظیمات حساس اتصال/نشست دستگاه از بکاپ عمومی حذف شده‌اند.
- بکاپ قدیمی حاوی SQLite باید با ابزار بازیابی مستقل تبدیل شود؛ ابزار `tool/recover_legacy_backup.py` اصل فایل را دست‌نخورده نگه می‌دارد.
- پیوست کوچک با شناسهٔ محتوایی منتقل می‌شود؛ سقف هر فایل ۴ MiB. مسیرهای قدیمی دستگاه باید دوباره پیوست شوند.

### UI و تجربهٔ کاربری

- خانهٔ جدید با خلاصهٔ روز، وضعیت sync، میان‌برهای قابل انتخاب و مرتب‌سازی و ظرفیت قابل تنظیم.
- کارت‌های فشرده روی موبایل برای دسترسی سریع‌تر به برنامهٔ روز؛ کارت‌های بزرگ‌تر و منوی کناری پایدار روی دسکتاپ.
- تم روشن/تیره، فونت فارسی Vazirmatn داخل بسته، رنگ و فاصله و کنترل‌های مشترک؛ حذف وابستگی‌های فونت آنلاینِ استفاده‌نشده.
- حفظ بزرگ‌نمایی متن سیستم؛ رفع overflow در عرض ۳۶۰ با ضریب متن ۱٫۴.
- مدیریت مشترک ویرایش، کپی، بایگانی، حذف و بازگردانی؛ یادداشت غنی با ویرایشگر اختصاصی باز می‌شود.
- پروفایل نام نمایشی، شغل، آواتار و سبک استفاده؛ نام و آواتار صفحهٔ پروفایل از رکورد ذخیره‌شده خوانده می‌شوند.
- تصاویر `ui/` از خود ویجت‌های Flutter، با فونت واقعی و دادهٔ نمایشی مستقل، رندر شده‌اند؛ اسکرین‌شات گوشی واقعی یا مرورگر زنده نیستند. تأیید تصویری انجام‌شده شامل خانه در موبایل روشن/تیره و دسکتاپ است، نه تمام صفحات.

### برنامهٔ روز، تقویم و یادآور

- تجمیع رویدادهای امور، دارو، خرید، پروژه، یادداشت، پرداخت و چرخه.
- تکرار مستقل از روشن‌بودن اعلان؛ پشتیبانی تقویم شمسی/میلادی و تکمیل هر نوبت عادت.
- اصلاح شروع و پایان دورهٔ دارو؛ داروی «در صورت نیاز» نوبت خودکار نمی‌سازد.
- زمان‌بندی حداکثر ۶۰ اعلان پیش رو پس از ذخیرهٔ پایدار، شامل تغییرات دریافت‌شده از sync؛ نیازمند تمدید با فعالیت بعدی برنامه.

### مالی، همکاری، نشانک و دستیار

- انتقال حساب مبدأ/مقصد، ثبت مبلغ کوچک‌ترین واحد به شکل عدد صحیح در JSON، تفکیک ارزها و حفاظت از حساب دارای گردش.
- بایگانی حساب بدون حذف سابقه، بدهی/طلب با اثر نقدی پس از تسویه، برنامهٔ اقساط با پیش‌نمایش سررسید؛ پرداخت بانکی انجام نمی‌دهد.
- گزارش بازه/حساب/دسته، CSV با حفاظت از فرمول، بودجه و هدف پس‌انداز؛ گزارش پس از ثبت بودجه تازه می‌شود.
- حساب سروری، درخواست/پذیرش دوستی، مسدودسازی، پیام، اشتراک کپی مستقل با سطح مشاهده/ویرایش و کنترل نسخهٔ سرور.
- نشانک و ورود/خروج HTML؛ افزونهٔ مرورگر فقط خروجی دستی نشانک می‌دهد.
- درخواست واقعی با کلید کاربر به سرویس OpenAI-compatible یا Gemini؛ پیشنهاد کار با تأیید کاربر وارد برنامه می‌شود. سرویس رایگان Raha تنظیم نشده است.

## نتیجهٔ آزمون‌ها

نتیجهٔ دقیق فرمان‌ها و نسخهٔ ابزارها در `VALIDATION_0.8.md` ثبت می‌شود. دامنهٔ بررسی شامل تحلیل ایستا، تست‌های Flutter/SQLite، مدل‌های دامنه، پروتکل PHP، بازیابی Python و ساخت release وب است. تست شبکهٔ واقعی MySQL/PHP، اعلان/ویجت روی Android و iOS، API واقعی دستیار و بستهٔ امضاشدهٔ موبایل در این محیط انجام نشده‌اند.

## محدودیت‌هایی که هنوز باید بسته شوند

| اولویت | کار باقی‌مانده | معیار پذیرش |
|---|---|---|
| P0 | تست سرور واقعی با دو حساب و دو دستگاه | قطع شبکه، ارسال دوباره، تعارض، حذف، مسدودسازی و دسترسی غیرمجاز در تست HTTP عبور کنند؛ اسکریپت و CI آماده‌اند |
| P0 | آزمون ارتقا روی دادهٔ واقعیِ کپی‌شده | بازیابی مستقل، شمارش رکوردها/پیوست‌ها و sync پس از ارتقا با نسخهٔ قبلی مقایسه شود |
| P0 | بازیابی اتمیک تنظیمات و DB | خطا بین نوشتن DB و preferences به حالت نیمه‌اعمال‌شده ختم نشود؛ اکنون تراکنش سراسری بین این دو ذخیره‌ساز وجود ندارد |
| P0 | دستگاه واقعی و امضای انتشار | نصب و ارتقا بدون حذف داده، مجوز اعلان، timezone، اعلان پس از راه‌اندازی مجدد و ویجت تأیید شوند |
| P1 | تکمیل فرم‌های اختصاصی همهٔ مدل‌ها | تمام فیلدهای قابل تغییر حساب/تراکنش/دارو و سایر مدل‌ها بدون تکیه بر فرم عمومی قابل ویرایش باشند |
| P1 | یکسان‌سازی UI تمام صفحات و دسترس‌پذیری | بازبینی صفحه‌به‌صفحه، صفحه‌کلید، screen reader، حالت خطا/خالی/بارگذاری و متن بزرگ؛ فعلاً تأیید تصویری خانه کامل‌تر است |
| P1 | پیام‌رسانی مقاوم در قطع اتصال | outbox پایدار، retry/backoff، وضعیت تحویل، صفحه‌بندی و اعلان؛ اکنون ارسال آنلاین و تازه‌سازی دستی است |
| P1 | همکاری روی دادهٔ اصلی | فهرست مشترک تعاملی و اتصال تغییرات به منبع؛ اکنون اشتراک کپی مستقل با ویرایش متن است |
| P1 | حساب عملیاتی | بازیابی گذرواژه، تمدید نشست و سیاست عضویت؛ حساب محلی فعلی قفل برنامه یا رمزگذاری DB نیست |
| P1 | پیوست بزرگ و پاک‌سازی | انتقال قطعه‌ای، ادامهٔ دانلود و جمع‌آوری فایل بی‌ارجاع؛ سقف فعلی ۴ MiB است |
| P1 | پروفایل/تنظیمات کامل بین دستگاه‌ها | تعیین روشن تنظیمات مشترک و اختصاصی دستگاه؛ چیدمان خانه فعلاً preferences محلی است |
| P2 | کارایی با دادهٔ حجیم | اندازه‌گیری با ۱۰هزار رکورد؛ جست‌وجوی ایندکس‌دار، محدودکردن گسترش تقویم و بکاپ جریانی؛ اکنون جست‌وجو در حافظه است |
| P2 | نشانک و افزونهٔ کامل | جست‌وجو، پوشهٔ تو‌در‌تو، pin و اتصال مستقیم با رضایت صریح؛ خروجی دستی فعلی جای sync افزونه را نمی‌گیرد |
| P2 | تکمیل مدل‌های دامنه | تاریخچهٔ مصرف دارو، ابزار مالی دقیق‌تر و دامنهٔ همهٔ فیلدهای تخصصی نیازمند توسعهٔ بعدی‌اند |

رمزنگاری سرتاسری رکوردهای همگام‌شده، OAuth مستقیم سرویس‌های ابری و تبدیل نرخ ارز پیاده‌سازی نشده‌اند. بکاپ رمز شده با sync رکوردِ قابل خواندن برای سرور تفاوت دارد.

## برای ادامه چه دسترسی لازم است؟

برای اصلاح کد همین فایل‌ها کافی بود و لازم نبود ابتدا تسک بیرونی بسازید. این جدول خودش backlog قابل انتقال است. برای اجرای یکپارچه و تحویل نصب‌شدنی، مخزن پروژه جهت CI، سرور آزمایشی خالی با HTTPS و تنظیمات محیط لازم‌اند؛ امضای Android باید با کلید مالک برنامه در secretهای CI تنظیم شود. کلیدها را داخل سورس یا پیام عمومی قرار ندهید. جزئیات خواسته‌های موجود در لینک گفت‌وگو، اگر جزو معیار نهایی‌اند، باید به صورت متن/خروجی قابل خواندن در دسترس باشند.
